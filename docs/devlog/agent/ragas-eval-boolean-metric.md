# RAG 评测口径改造：布尔命中率（boolean metric）

- 日期：2026-09-18
- 类别：agent / 评测
- 关联提交：待补

## 背景

用户拍板：放弃 RAGAS 全量重跑（225 项约 1h+、10 条小样本不准），将 `eval_retrieval.py` 的
recall 口径从「关键词覆盖率」改为「布尔命中率」——更接近生产体验（LLM 拿 top5 文档能否答出答案要点）。

## 改动（`src/ragas_test/eval_retrieval.py`）

1. `evaluate_recall` 支持双口径：
   - `metric="boolean"`（**默认**）：句级要点覆盖布尔命中率
     - ground_truth 按句切分（。！？；）
     - 句子覆盖 = 该句核心关键词命中 top-k 文本比例 **≥ 0.6**（允许个别词字面差异，如「用于/支持」）
     - query 命中 = 覆盖句占比 **≥ 0.5**（过半答案要点有文档支撑）→ 返回 1.0/0.0，avg 即命中率
   - `metric="coverage"`：保留旧关键词覆盖率口径（长答案整串匹配惩罚重，已非默认）
2. `_sentence_keywords` 改用 **jieba 对句内中文切词**：消除 `re.findall` 把连续中文抓成
   超长整串的问题（旧 coverage 口径的长答案惩罚在句子级同样存在）
3. 新增 `--metric boolean|coverage` 参数（默认 boolean）；报告 JSON 的 `config` 增加 `metric` 字段

## 实测（45 条刁钻 QA，0.25 阈值，RedisSearch 6379）

| 口径 | 单路 avg | 混合 avg | 单路 median | 混合 median |
|---|---|---|---|---|
| coverage（旧） | 0.2774 | 0.2570 | 0.2000 | 0.1753 |
| boolean（初版：句内 AND 全关键词） | 0.0889 | 0.0667 | 0.0 | 0.0 |
| boolean（放宽：句内 ≥60% 关键词） | **0.3111** | **0.2667** | 0.0 | 0.0 |

- 迭代结论：句内 AND 全关键词过严（语义等价字面不同即误杀，如「用于/支持」），
  命中率无区分度；放宽到句内 ≥60% 关键词命中后，单路 8.9% → 31.1%，混合 6.7% → 26.7%。
- 中位数 0：45 条刁钻 QA（含 15 条 Badcase）+ 405 chunks 小知识库，过半 query 的 top5
  不足以覆盖过半答案要点——这是真实水平，不是口径误差。
- 混合 avg 低于单路：rerank + 过滤（0.25）会排掉「含关键词但低相关」文档，与之前 coverage 口径结论一致。
